# Web Technologies Mind Map

A structured, teachable map of web technologies — from internet basics, through the evolution of the
web, to modern development practice. Built as a teaching tool and usable as a quick reference.

**193 concepts** across six sections, each with a definition and links to authoritative sources.

## How to use this

- **Start with the mind map** to see the shape of the field and how the areas relate.
- **Use the reference** when you need a definition or a primary source for one specific thing.
- **Search** (top of the page) covers every definition, not just titles.

Concepts are marked `emerging` where a technology is still settling, and `legacy` where it is
superseded but still widely encountered in older tutorials — jQuery, AngularJS and Heroku, for
example. Nothing is deleted for being dated, because students meet dated material and need to
recognise it.

## A note on Web 3.0

In this map, **Web 3.0 means the Semantic Web** — the W3C programme of making data machine-readable
through RDF, ontologies and linked data. **Web3** is a separate, later term from the cryptocurrency
industry. The two are routinely conflated; the
[disambiguation note](reference/02-evolution.md#web3-disambiguation) explains the difference.
